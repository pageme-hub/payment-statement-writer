간이지급명세서 자동입력기를 만들어라.

1. 핵심 기능
- 엑셀 파일을 열어 특정 시트의 특정 셀 또는 범위를 파싱
- 엑셀 파일을 열어 특정 시트의 특정 셀 또는 범위에 내용을 기록
- json 파일로 입력/기록 매핑 관리

2. 기본 UI
- 파일 선택 버튼, 경로표시 라벨 2개씩 (정산서, 명세서)
**명세서 버튼 밑에는 추가 설명 라벨 배치
- 년, 월 선택 콤보박스
- 작업 시작 버튼
- 작업 현황 로그화면

3. 프로그램 로직
1) 정산서 파일, 명세서 파일 선택
2) 정산서 파일이 'ㅇㅇ mm월 w주차 정산표.xlsx' 포맷을 가지므로, 파일명에서 월('mm')을 추출하여 현재 날짜와 비교하여 년도 추측하고 년,월 콤보박스 자동으로 수정
3) 작업 시작 버튼을 누르면 정산서 파일, 명세서 파일 로드
4) 정산서 파일 '월간정산' 시트의 B1:B100에서 값이 1 이상 숫자인 행을 추출
5) 정산서 파일 '월간정산' 시트의 C,I,J,K열을 파싱해서 배열로 저장하되, 행은 앞 과정에서 추출한 행에 대해서만 저장
6) 배열을 명세서 파일 'Sheet1' 시트의 E,H,J,K에 입력. 시작행은 2행
7) 데이터가 입력된 행의 나머지 열에 아래 내용을 기입
 - A열 : 행번호-1
 - B열 : 콤보박스의 년도
 - C열 : 콤보박스의 월
 - D열 : 940918
 - G열 : 1
 - I열 : 3
8) 명세서 파일을 프로그램이 있는 폴더에 '간이지급명세서_ㅇㅇyy년m월분.xlsx'로 저장. ㅇㅇ = 업체명(정산서파일 참고), yy=연도, m=월

4. 주의사항
- 기존에 적용된 서식을 변형하지 말 것
- 매핑은 반드시 하드코딩이 아닌 setting.json에 저장하여 관리할 것
- 명세서 파일은 로드 시 위치를 setting.json에 기록하여 프로그램 실행 시 자동으로 로드하도록 처리
